# Assets

Binary assets for the exhibit: 3D models, audio, and reference imagery. Large binary types are tracked with Git LFS, see `.gitattributes` at the repo root.

Everything in this folder depicting or scoring the MurderBird falls under the content carve-out in [../NOTICE.md](../NOTICE.md), not the repo's MIT license.

- `models/` — 3D geometry, rigs, exported GLB/GLTF
- `audio/` — theme song stems, final mix, and interaction SFX
- `images/` — concept art and reference stills (working copies; canonical story images live on overkillhill.com)
