# Orbital saddle study V9

This one-shot local reconstruction cuts only the two fixed orbital mounting plates with a conservative ±1 mm expanded convex hull of the unchanged evaluated brows. It preserves the broad brow surfaces and all other scene data.

See [receipt.json](receipt.json) for native/input hashes, save-reload preservation, optical-seat and pin6 observations, 41 lift samples, topology, and matched views. This proposal is not exported, selected, or accepted.
