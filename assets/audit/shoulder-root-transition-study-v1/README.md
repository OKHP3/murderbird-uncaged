# Shoulder-root source inventory

This read-only inventory records the upper torso and shoulder meshes of selected Alignment V9 at native rest. It was prepared to guide the next coupled shoulder-root construction study. It contains no corrected geometry, native candidate, or clearance result.

Native coordinates are metres with Z up, negative Y forward and positive X anatomical left. Bounds describe source vertices in world space, before modifiers; they are not surface-to-surface distances. The current pod-like shoulder transition remains an open likeness issue. The selected source and script are preserved; no application or source-model object changed.
