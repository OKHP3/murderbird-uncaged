# Neutral v2 review evidence

This folder is the local Stage B correction packet for GLB SHA-256 `48229ba5526ccd7a227db56d225ef88643eb6b3388eb07662452cc2c67636ac7`. It is not the old inspector packet, a public release or artistic acceptance. Start with `neutral-review.html` and `docs/correction-v2-stage-b-review.md`.

- `neutral-*` and era `*-reference-perspective` / front / rear / left / right PNGs are authoring renders. `authoring-views.json` records projection and camera conventions.
- `baseline/` contains new renders of the preserved old exterior-v1 model at those same authoring cameras. Its different preview materials are explicitly disclosed.
- `browser-validation.json` and `screenshot-manifest.json` record the first frozen-model WebGL, inspection and fallback run. Its narrow label check incorrectly accepted zero-size hidden controls. **`label-validation.json` supersedes that subset**, with positive visible bounds, real desktop/narrow spacing and keyboard checks. The 36 label PNGs are replaced by that corrected retest; they are not evidence for the flawed old assertion.
- `*-frozen-*.png` and `frozen-extrema.json` use the actual pause control to hold live jump/thrust/contact and jaw poses while orbiting. The plain `*-extreme.png` files are earlier freely running phase samples; they do not certify the maximum phase.
- `neutral-motion-demonstration.webm` is the original silent browser recording. MP4 is its H.264 viewing derivative, 1600×1400, 25 fps, 116.96 seconds including setup. The measured control sequence is 115.786 seconds. `motion-demonstration.json` records the exact candidate, environment, visible clock origin, events and samples. This is not either of the required 120-second no-input acting runs.
- `candidate-assessment.json` binds runtime/tool source hashes and bounded receipts to this model. It preserves open findings and pending decisions; it is not a PRD passing scorecard.
- `earlier-trials/` holds a superseded fallback-failure capture from the earlier D iteration (preserved fully under the model iterations directory). It is not a final-candidate screenshot.

Technical passes do not close likeness or certify all moving intersections, physical support, screen-reader use, human acting/audio quality or real mobile performance. Original references, source story, old assessment and historical receipts remain untouched. This folder, editable models and iterations are not copied into the built website. Nothing here authorizes publication.
