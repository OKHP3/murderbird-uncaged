# Next proposal only: carry the complete existing guard course

Moving all ten **existing directional plates** in course2 on one skeletal carrier would remove the two moving/static same-course boundaries by construction: guards1/2 and4/5 would have no relative carrier motion. This is an ownership change, not proof that their original rest geometry is clear.

It need not become a new visual collar: retain the ten separate long, swept forms, angular service gaps and varied edges; add no circular rim, continuous cylindrical sleeve or spherical band. A sparse internal carrier would connect existing plates rather than bridge their exterior gaps. Mechanically it is still a rigid circumferential course; calling the pieces separate does not make them independent. Its visual and access consequences therefore require explicit review.

A full-course carrier could fix the **seam architecture** of the three-plate partition, but it does not fix the current guide hardware intersections or its six course2-to-course3/4 crossings. The posterior and lateral sectors introduce new body/mantle/head sweep constraints. The travel must be derived again from all ten actual solids with actual finite guide hardware, and useful directional likeness must remain the gate. Do not infer that one smooth front-only cam can safely drive the complete course.

If this ownership change is scoped later, rename the carrier `cervical-mid-a-guard-course-slide`, reparent course2 directional guards1–10, and describe all ten in the optional guide metadata. Retain the load chain only as an experiment constraint, not owner-approved pivots. No implementation or further iteration was performed for this proposal.
