# Orbital and crown V14

Versioned local construction proposals derived from the preserved V13 native scene. They are not accepted likenesses or production releases. The current review is **attempt 11**; see [its checkpoint record](../../../docs/orbital-crown-v14-checkpoint.md) for scope, references, hashes, evidence and unresolved appearance.

Each successful attempt preserves an editable Blender source. Attempts 03, 05, 09 and 11 also retain diagnostic runtime exports. Attempt 07 failed before a native save; its failure record remains in the matching audit directory. Earlier attempts must not be substituted for the current review merely because an export exists.

Attempt 11 changes eye placement, orbital support, brows, crown guards, cheek fit and Advanced processing packaging. It preserves all 52 pivots, 613 unrelated meshes and 462 historical curves from V13. Its 126 changed meshes remain rigid mechanical construction. Materials and era eligibility tags are retained, not newly artistically approved.

Regeneration uses a new attempt directory and preserves prior sources. Executed generator copies, rendered comparisons and fit/export receipts remain under `assets/audit/uncaged-orbital-crown-v14/`. Files named `review-page-snapshot.html` there preserve earlier page bytes; their relative links are archival and they are not standalone review pages.
