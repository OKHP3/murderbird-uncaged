## Production method and next correction

The current procedural solid-envelope method is useful for parenting, repeatable export and motion contracts, but these views demonstrate its limit: repeated courses, a generic optic ring/cheek bridge, coarse limb channels and rounded mantle pods do not reproduce the defining construction. More texture work would not resolve that.

The next geometry pass should use the existing Blender source with explicit region-specific profile curves and cross-sections constrained by the scoped side/three-quarter references: first the cheek/mandible and bill root, then nonuniform shoulder/breast plate boundaries and shaped limb guards. Preserve manually edited control meshes in a new native version before regeneration. Keep rigid owners, current naming, era eligibility and browser export constraints; use deforming geometry only for justified flexible links. No runtime architecture, dependency, purchase or upload is needed. Acceptance evidence is the same matched views and frozen/normal-speed poses, followed by independent critique; dependent material work remains gated.
