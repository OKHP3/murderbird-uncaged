# Project agent skills

These seven complete packages are installed from `OKHP3/skillz` revision
`2cec142b89400c2a51eea74328f8528225ef9899`. Source files are preserved unchanged.
See [installation provenance](../../provenance/skill-installation.json) for paths and SHA-256 hashes.

Repository `AGENTS.md`, `NOTICE.md`, and the repository boundaries govern their use.
Load only the skill needed for the task. Installation does not establish behavioral validation.

For exhibit changes, retain Vite, Three.js, and Web Audio. Follow the repository build
requirements and check both WebGL and the illustrated fallback for scene changes.
Brand profiles do not replace approved character references or story authority.
Private session archives remain local and ignored; skills and provenance are not runtime assets.

Invoke a workflow by naming the skill and the artifact or task to which it should apply.
These packages should be discoverable on the next turn of a compatible agent host.
